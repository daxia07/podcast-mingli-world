# video.mingli.world companion

Work in this isolated directory. The existing podcast checkout and deployment must remain unchanged.
Read README.md and RELEASE.md before publishing. Use the inspected vanilla ES module + Cloudflare Pages architecture. No framework build, paid API, credentials in source, account-persistence claims, public interaction data, or third-party analytics.

`site/content.json` is the editorial source of truth. Every idea needs speaker, date type, official source, evidence location, commercial/historical context, and separated paraphrase / editorial interpretation or conditional outlook / practical experiment. Chapter anchors are navigation aids, never reviewed clip boundaries. Do not download or rehost full talks or transcripts.

Run `npm test`, `npm run validate`, and headless acceptance tests after changes affecting interactions. Review screenshots at 320px, 390px and desktop widths. Native foreground browser control requires coordination with the parent task.

Deployment is currently blocked by automatic approval review of a push to the podcast repository. Do not bypass with another upload or workflow. Get approval for the concrete companion-only CI plan or a separately authorized existing credential route.
