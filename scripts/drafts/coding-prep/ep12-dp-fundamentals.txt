Dynamic programming fundamentals. Climbing stairs, house robber, coin change fewest coins. The speech pattern matters more than memorizing ten problems. No AI. Speak before solve. Pair with DP Search List in the app.

What DP is in interview words. Optimal substructure — big answer builds from smaller. Overlapping subproblems — same sub-answers reused. You define dp meaning in one sentence, base cases, recurrence, then iterate bottom up or memo top down. Always state that sentence before code.

Problem one. Climbing stairs. n steps. Each move one or two steps. Ways to reach the top.

Cold open. Eight counts. Recurrence and base. One through eight.

Model: dp of i equals ways to reach step i. dp one equals one. dp two equals two. dp i equals dp i minus one plus dp i minus two. Fibonacci. O of n time O of one space with two rolling variables.

Walk. n five. Sequence one two three five eight. Answer eight.

Dead-end: recursion without memo exponential. Say it, then add memo or bottom up.

Problem two. House robber. Array of money per house. Cannot rob adjacent houses. Max money.

Cold open. Eight counts. State meaning. One through eight.

Model: dp i equals max money using houses up to index i. dp i equals max of dp i minus one — skip this house — versus dp i minus two plus nums i — take this house. Base dp zero equals nums zero. dp one equals max of first two.

Walk. Two one one two. Compute carefully: take two and two equals four, or other paths. Answer four.

Edges. Empty. One house. Two houses. All zeros.

Problem three. Coin change. Coins of given denominations, unbounded use. Fewest coins to make amount. Or negative one if impossible.

Cold open. Ten counts. What dp of x means. One through ten.

Model: dp x equals minimum coins to make sum x. Init dp zero equals zero, others infinity. For each coin, for x from coin to amount: dp x equals min of dp x and dp x minus coin plus one. Answer dp amount or negative one if still infinity.

Walk. Coins one two five. Amount eleven. Classic path five five one — three coins.

Dead-end: greedy largest coin first — fails some coin systems. DP is the safe interview default unless they prove canonical coin system.

Complexity O of amount times number of coins. Space O of amount.

Pattern cue speech you must own. I will define dp of i as… Base cases… Transition… Order of iteration… Complexity…

If you cannot say the meaning of the cell, do not code yet.

Transfer. Fifteen seconds. Climbing stairs three steps allowed one two or three — how recurrence changes. One through fifteen.

Model: dp i equals sum of dp i minus one two and three with care at bases.
