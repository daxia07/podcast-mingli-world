Problem one. Maximum depth of binary tree. Root to leaf longest path length in nodes.

Cold open. Six counts. One line recurrence. One through six.

Model: if null depth zero. Else one plus max of depth left and depth right. Recursive DFS. Iterative stack or level BFS also works — BFS depth is number of levels.

Walk. Skewed left chain of three — depth three. Balanced small — compute both sides.

Edges. Empty zero. Single node one.

Problem two. Invert binary tree. Swap every left and right child recursively.

Cold open. Six counts. One through six.

Model: if null return. Swap left and right, then invert both children — or invert then swap, be consistent. Return root.

Dead-end: only swapping at root. Must visit all nodes.
