1. Ask the right Two Sum clarifiers without freezing  
2. State nested-loop O(n²) without shame  
3. Implement map complement **lookup-before-insert**

5. State O(n)/O(n) and when sort+pointers is better  

## Honest limits

- Audio will **not** replace timed coding with fingers  
- Won't invent company-secret LC numbers (vault says none public)  
- Benefit peaks when you **speak along** and then do the app options  

## Script hygiene

Listener-facing scripts must **not** contain:

- `[INTRO]`, `[pause]`, `[CLARIFY — 90 sec]`
- `====` section banners
- producer metadata in the spoken file

Those belong in `SERIES.md` or pipeline config only.
