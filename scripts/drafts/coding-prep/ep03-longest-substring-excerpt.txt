Problem: longest substring without repeating characters. Return the length.

Clarify first. Empty string? Character set? Case sensitive?

Naive: for every start, expand end while unique. O of n squared.

Optimal: sliding window. Left and right. Right moves from zero to n minus one. Keep a set of characters in the window. When the character at right is already in the set, advance left, removing characters as you go, until the duplicate is gone. Then add the new character. Update the answer with right minus left plus one.

Example: a b c a b c b b.

Window a b c. Length three. Next a is a duplicate. Move left past the first a. Window becomes b c a. Still length three. Keep going. Best stays three.

Why is this O of n, not O of n squared? Because left and right only move forward. Each index enters and leaves the window at most once.

Say it back: expand right, shrink left on duplicate, track max length.
