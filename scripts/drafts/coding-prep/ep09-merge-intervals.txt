Merge Intervals. Sort plus linear scan. Shows up in calendars, bookings, and range logic. No AI. Speak before solve. Pair with Intervals and Design in the app.

Problem. Given a list of intervals, each a start and end, merge all overlapping ones. Return the merged list sorted by start.

Cold open. Ten counts. First step and merge rule. One through ten.

Model: sort by start ascending. Keep a current interval. For each next: if next start is less or equal current end, merge — current end becomes max of ends. Else push current and start a new current. Push the last. Clarify whether touching endpoints merge — usually closed intervals, equal end and start do merge.

Ritual. Restate. Clarify inclusive bounds. Mutate okay. Output order. Naive. Improve. Example. Edges. Complexity.

Naive: repeatedly scan for any overlapping pair and merge until stable — messy and slow. Better after sort is one pass.

Walk. Intervals one three, two six, eight ten, fifteen eighteen.
Sort already ordered. Current one three. Next two six overlaps — end becomes six. Current one six. Next eight ten no overlap — emit one six, current eight ten. Next fifteen eighteen — emit eight ten, current fifteen eighteen. Emit last. Result three intervals.

Touching case. One two and two three. If inclusive, merge to one three. Say the rule out loud before coding.

Dead-end: sort by end instead of start without care — merge logic gets awkward. Prefer sort by start. Another dead-end: forgetting to emit the last current.

Edges. Empty input. Single interval. All overlap into one. No overlaps. Contained interval fully inside another. Negative coords if allowed. Unsorted input — must sort.

Complexity. O of n log n from sort. Space O of n for output, or O of one extra if you overwrite carefully — say both.

Meeting rooms one-liner transfer. Can you attend all meetings? Sort by start, check each next start is greater or equal previous end — or sort starts and ends separately. Different question, same sort instinct.

Pattern cue. Ranges on a line — sort by start, sweep. Overlap test: not completely left and not completely right. Say it.

Transfer. Fifteen seconds. Insert a new interval into a sorted non-overlapping list — approach. One through fifteen.

Model: add new interval, then run the same merge pass. Or binary search position then merge neighbors.

Speed recap.

Merge intervals: sort by start, scan, merge when next start less or equal current end using max end, emit when gap. O of n log n. State inclusive touch rule. No AI.
